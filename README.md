# 🐉 Τα Μαγικά Νησιά

**Παίζεται στο «Τα Παιχνίδια μας»**, το hub με όλα τα παιχνίδια του σπιτιού (κάρτα «Τα Μαγικά Νησιά», διαδρομή
`/magic-islands/`). Οι διευθύνσεις παραγωγής και staging είναι στο README του games-hub (το repo αυτό είναι
δημόσιο: χωρίς hostnames).

**Ηλικία:** 6+ · tablet (οριζόντια), κινητό ή υπολογιστής · παιχνίδι-αναφορά του
[GAME-STANDARD](https://github.com/konzag/games-template/blob/main/GAME-STANDARD.md) (v1.2).

Το README είναι και ο **οδηγός χειροκίνητης δοκιμής** (GAME-STANDARD §2a): οθόνες, λίστα δοκιμών MI-xx, τι
άλλαξε, περιορισμοί, ασφαλής δοκιμή και αναφορά προβλήματος.

## Η ιστορία

Ένας κακός, ο Μαγοφάγος, θέλει να πάρει όλη τη μαγεία από τα 4 νησιά. Δύο πνεύματα, ο **Ναπολέων** (νερό,
ήλιος, φύση) και η **Αριάνα** (καιρός, χιόνι, πάγος), πετάνε με τον δράκο τους, τον **Ζαφείρη**, για να τη
σώσουν. Σε κάθε νησί βρίσκουν φίλους, μαζεύουν κλειδιά και διώχνουν τα κακά ξόρκια. Αν κουραστούν, ο Ζαφείρης
τους γυρίζει πίσω για να ξαναπροσπαθήσουν.

## Χειρισμός

| | Πληκτρολόγιο | Αφή |
|---|---|---|
| Κίνηση | βελάκια ή WASD | ακούμπα στο αριστερό 45 % της οθόνης και σύρε (joystick που εμφανίζεται κάτω από τον αντίχειρα) |
| Ξόρκια | 1 2 3 4 | κουμπιά κάτω |
| Η Ίριδα βοηθάει (μία φορά σε κάθε νησί) | Space | 🌈 |
| Αλλαγή ήρωα | Q ή Tab | 🔄 ή κάρτα ήρωα |
| Παύση | P ή Esc | ⏸ |
| Ήχος · πλήρης οθόνη | M · F | 🔊 · ⛶ |
| Διάλογοι, επόμενο | Enter ή Space | ▶ |
| Πίσω στα παιχνίδια | | 🏠 |

Το joystick είναι αναλογικό (360°): όσο πιο μακριά σέρνεις, τόσο πιο γρήγορα. Με δεύτερο δάχτυλο πατάς ξόρκια
ταυτόχρονα. Το παιχνίδι μπαίνει σε παύση όταν κρύβεται η καρτέλα ή χάνεται η εστίαση.

## Οθόνες και ροή

Τίτλος → (πτήση) → νησί: διάλογοι, κύματα, αρχηγός, κλειδί → πτήση στο επόμενο νησί → … → νίκη. Ήττα: πίσω στη
Μονοκέρια. Τα κείμενα όπως φαίνονται στην οθόνη:

1. **Τίτλος:** «Τα Μαγικά Νησιά», «Ένας κακός θέλει να πάρει όλη τη μαγεία από τα 4 νησιά. Δύο πνεύματα πετάνε με
   τον δράκο τους για να τη σώσουν!», οι ετικέτες «🌸 Ναπολέων · νερό, ήλιος, φύση», «❄️ Αριάνα · καιρός, χιόνι,
   πάγος», «🐉 Ζαφείρης ο δράκος», ο πίνακας πλήκτρων, το κουμπί **«Ξεκινάμε! ✨»** και ο σύνδεσμος «🏠 Πίσω στα
   παιχνίδια». Αν υπάρχει αποθηκευμένη πρόοδος, εμφανίζεται και **«Συνέχεια: <νησί> ▶»** (π.χ. «Συνέχεια:
   Γοργονία ▶»). Enter στον τίτλο συνεχίζει όταν υπάρχει save.
2. **Κάρτα ήρωα και αλλαγή:** πάνω αριστερά δύο κάρτες, «🌸 Ναπολέων» και «❄️ Αριάνα», με μπάρα ζωής. Η κάρτα του
   ήρωα που παίζει είναι τονισμένη· 💤 = κοιμάται. Αλλαγή ήρωα με Q/Tab, με το κουμπί «🔄 Αλλαγή» ή με πάτημα στην
   άλλη κάρτα («Παίξε με τον Ναπολέοντα» / «Παίξε με την Αριάνα»). Ξόρκια:
   - Ναπολέων: «Κύμα Νερού», «Ηλιαχτίδα», «Αγκαθωτά Κλαδιά», «Γιατρειά» (ξυπνά και τον άλλον)·
   - Αριάνα: «Κεραυνός», «Χιονοθύελλα», «Παγοκρύσταλλος», «Ασπίδα»·
   - «🌈 Ίριδα» (Space), μία φορά ανά νησί· μετά «Η Ίριδα ξεκουράζεται 🌈».
3. **Τα 4 νησιά** (με τη σειρά), το καθένα με διαλόγους της Ίριδας («ΙΡΙΔΑ»), κύματα («Κύμα 1/3»), αρχηγό
   («Ο αρχηγός!») και κλειδί («Το κλειδί!», «Πάρτε το κλειδί! 🗝️»):
   - **Μονοκέρια**, το νησί της Φύσης· αρχηγός η Ραβεντζίλα·
   - **Γοργονία**, κάτω από τη θάλασσα· αρχηγός ο Μπαρμπαρόσα·
   - **Κρυσταλία**, το νησί του Χρόνου· αρχηγός η Πρίσμα («Ο χρόνος παγώνει! ⏳»)·
   - **Αγάπη**, το νησί της Φιλίας· αρχηγός ο Μαγοφάγος· «💖 μαζί!» όταν οι δύο ήρωες είναι κοντά.
   Ανάμεσα στα νησιά η πτήση «Ο Ζαφείρης πετάει στην …!» με «Συνέχεια ▶» για παράλειψη.
4. **Ήττα:** «Ωχ! Κουραστήκαμε…», «Ο Ναπολέων και η Αριάνα αποκοιμήθηκαν. Ο Ζαφείρης τους ξυπνάει για να
   ξαναπροσπαθήσουν στο ίδιο νησί. Τα κλειδιά σας μένουν! 🗝️», κουμπί «Ξανά από την αρχή 🐉» (ή Enter): ξεκινά **το ίδιο
   νησί** από την αρχή, με τα κλειδιά που έχετε ήδη (GAME-STANDARD §6, η ήττα δεν τιμωρεί). Η αποθηκευμένη πρόοδος
   **μένει**: ο τίτλος δείχνει ακόμα «Συνέχεια: <νησί> ▶».
5. **Νίκη:** «Νικήσατε!», «Ο Μαγοφάγος έφυγε για πάντα και η μαγεία γύρισε σε όλα τα νησιά. Όλοι οι φίλοι σας
   ήρθαν να γιορτάσουν!», κουμπί «Παίξτε ξανά 🎉» (ή Enter) → τίτλος. Μετά τη νίκη η πρόοδος σβήνει (νέο ξεκίνημα).
6. **Παύση (P, Esc, ⏸):** «Παύση», «Πάρτε μια ανάσα. Ο Ζαφείρης περιμένει!», «Συνέχεια ▶», «🏠 Πίσω στα παιχνίδια».
7. **Κουμπιά πάνω δεξιά, πάντα ορατά:** 🔊 «Ήχος», ⏸ «Παύση», ⛶ «Πλήρης οθόνη (F)», 🏠 «Πίσω στα παιχνίδια».
8. **Εφέ (σωματίδια, ζωγραφισμένα με κώδικα):** κάθε εφέ έχει δικό του **σχήμα**, όχι μόνο χρώμα, και λεπτό σκούρο
   περίγραμμα ώστε να φαίνεται και στο λευκό χιόνι:
   - **κλειδί:** όσο περιμένει στο έδαφος λαμπυρίζουν γύρω του μικρά χρυσά αστεράκια· όταν το παίρνετε, έκρηξη από
     χρυσά/λευκά αστέρια με 4 μύτες και δύο κύκλοι που ανοίγουν·
   - **ξόρκι:** σε κάθε ξόρκι (1–4) γύρω από τον ήρωα πετάγονται **φυλλαράκια** (Ναπολέων, πράσινα/κίτρινα) ή
     **ρομβάκια πάγου** (Αριάνα, γαλάζια/λευκά)·
   - **🌈 Ίριδα:** αστέρια σε όλα τα χρώματα του ουράνιου τόξου γύρω και από τους δύο ήρωες·
   - **νερό:** όταν ο Ζαφείρης βουτά στη θάλασσα (πτήση προς τη Γοργονία) σταγόνες και δύο κύκλοι στο νερό· όπου
     χτυπά το «Κύμα Νερού» μικρές σταγόνες·
   - **νίκη:** τα πυροτεχνήματα της οθόνης «Νικήσατε!» είναι από τα ίδια σωματίδια.
   Με τη ρύθμιση συσκευής «λιγότερη κίνηση» (prefers-reduced-motion) **δεν υπάρχει κανένα σωματίδιο**.

## Αποθήκευση

- Μόνο **στη συσκευή** (localStorage), κλειδί **`magic-islands.progress.v1`** (αμετάβλητο). Κρατά το πιο μακρινό
  νησί που έφτασες (και τα κλειδιά πριν από αυτό). Γράφεται όταν παίρνετε το κλειδί ενός νησιού· μια ήττα δεν
  παίρνει ποτέ πίσω πρόοδο· «Ξεκινάμε! ✨» δεν τη σβήνει· σβήνει μόνο μετά την τελική νίκη.
- Δεν υπάρχει αποθήκευση στο σπίτι (server), ούτε προφίλ ή PIN. Τίποτα δεν στέλνεται πουθενά.
- Η επιλογή του διακόπτη 🌓 (συσκευή / φωτεινά / σκοτεινά) θυμάται σε **δικό της** κλειδί,
  `magic-islands.theme.v1`, μόνο όταν πατηθεί ο διακόπτης. Το κλειδί της προόδου και η τιμή του δεν αλλάζουν.
- Το hub δείχνει «Συνέχεια» στην κάρτα του παιχνιδιού όταν υπάρχει αυτό το κλειδί στη συσκευή.

σε ιδιωτικό παράθυρο (incognito)**, ώστε το `magic-islands.progress.v1` στη συσκευή των παιδιών να μην
αντικατασταθεί ή σβηστεί. Μεγέθη: 1280×800, 1180×820 (αφή), 820×1180 (αφή), 780×360 (κινητό οριζόντια, αφή), 360.

## Γνωστοί περιορισμοί

- Το φωτεινό θέμα αλλάζει μόνο το «κέλυφος» (κάρτες, μενού, κουμπιά, HUD, διάλογο)· ο κόσμος των νησιών στον καμβά
  μένει ίδιος. Ο διακόπτης 🌓 είναι στον τίτλο και στην παύση, όχι στο HUD (στα 360 px δεν χωρά πέμπτο κουμπί).
- Τα φόντα με βάθος φαίνονται κυρίως στις γωνίες: το νησί γεμίζει σχεδόν όλη την οθόνη.
- Μετά από αλλαγή μεγέθους του παραθύρου το νησί σχεδιάζεται λίγο πιο αργά μέχρι το επόμενο νησί (ίδια εμφάνιση).
- Φτιαγμένο για οριζόντια οθόνη· δεν δείχνει μήνυμα «γύρισε τη συσκευή». Στο 360 κάθετα τα αυτόματα tests
  ελέγχουν μόνο τα εφέ (0 σφάλματα), όχι τη διάταξη (αυτή: 1280, 1180×820, 820×1180, 780×360).
- Εφέ νερού υπάρχουν μόνο εκεί που το παιχνίδι έχει πραγματικά νερό: η βουτιά του Ζαφείρη στη Γοργονία και το
  «Κύμα Νερού». Βάρκα δεν υπάρχει, και η πτήση από τη Γοργονία δεν δείχνει έξοδο από το νερό.
- Με «λιγότερη κίνηση» χάνονται και οι σπίθες όταν φεύγει ένας εχθρός και τα πυροτεχνήματα της νίκης (ο εχθρός
  απλώς εξαφανίζεται).
- Όταν τα 250 σωματίδια είναι όλα σε χρήση, ένα νέο εφέ παίρνει τη θέση ενός παλιού (το πιο πρόσφατο εφέ
  φαίνεται πάντα).
- Η πρόοδος είναι μόνο στη συσκευή και μόνο ανά νησί (όχι ανά κύμα)· καθάρισμα δεδομένων του browser τη σβήνει·
  δεν υπάρχουν προφίλ ούτε θέσεις.
- Δεν παίζει χωρίς δίκτυο (χωρίς service worker από το 2026-10-14).
- Το `/?e2e` ανοίγει έναν «αισθητήρα» για τα Playwright tests (κατάσταση, μετρητές σωματιδίων και ένα κουμπί
  δοκιμής που ρίχνει σπίθες)· στο κανονικό παιχνίδι δεν υπάρχει.

## Το repo

Στατικό παιχνίδι (GAME-STANDARD §2): όλο το παιχνίδι είναι το `index.html` (ένα `<style>`, ένα `<script>`,
χωρίς build). Το games-hub το σερβίρει στο `/magic-islands/` ως git submodule, καρφωμένο σε SHA.

```
index.html              το παιχνίδι
assets/                 εικονίδια (icon.svg, icon-180.png)
tests/smoke.spec.ts     Playwright: φόρτωση, 10 δευτ. με πλήκτρα και με αφή, 0 σφάλματα, CSP του hub
tests/joystick.spec.ts  το αιωρούμενο joystick (8 κατευθύνσεις, νεκρή ζώνη, δύο δάχτυλα, διάταξη, axe)
tests/readme.spec.ts    οι εννέα ενότητες αυτού του README, οι αριθμοί MI, τα issue templates
tests/look.spec.ts      G1-GFX: όλες οι οθόνες σε 4 μεγέθη × light/dark (0 σφάλματα, axe), στρώματα, βάθος,
                        «λιγότερη κίνηση», ζωντανό πορτρέτο, όριο σωματιδίων, παλιά αποθήκευση
tests/perf.spec.ts      μόνο για σύγκριση (PERF=1): καρέ/δευτ. και χρόνος ανά καρέ, κανονικά και CPU 4× πιο αργή
tests/evidence.spec.ts  μόνο για εικόνες (EVIDENCE=<φάκελος>): όλες οι οθόνες σε 4 μεγέθη × light/dark
tests/serve.mjs         μικρός server που μιμείται το hub (ίδιο CSP: tests/hub-csp.mjs)
```

```bash
npm ci && npx playwright install chromium
CI=1 npx playwright test   # desktop (πληκτρολόγιο) + tablet (αφή) + κινητό/κάθετο tablet για το joystick
npm run serve              # http://127.0.0.1:4173/
```

Ροή: feature branch → PR στο `staging` → CI πράσινο → release PR → **GO** → `main` → PR στο games-hub που
μετακινεί το submodule.

Ιστορικό: μέχρι τις 2026-10-14 το παιχνίδι είχε δικό του server app. Αποσύρθηκε όταν μπήκε στο hub (το ιστορικό είναι στο git).
